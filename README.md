# Blazwitcher 拼音搜索

在 Raycast 窗口内搜索 Chrome 标签页、书签和历史记录。保留 A 方案的单栏结构：搜索框、来源筛选、结果数量、来源图标、标题、灰色网址、来源标签和底部操作栏，不显示右侧详情。

**当前限制：行内彩色命中高亮尚未实现。** Clipboard History 使用 Raycast 内部 `HighlightRoot`，第三方 `List.Item` 没有相同接口。搜索仍由 `text-search-engine@1.5.3` 完成，并保留原文命中区间；`zhoubao` 能找到“周报”，但目前列表不会为这两个字着色。不添加「」等标记，也不使用独立浮窗或详情栏替代。

## 开发与使用

详细的本地安装、调试、权限排查与卸载步骤见 [贡献指南](CONTRIBUTING.md)。

需要 macOS、Google Chrome、Raycast、Node.js 22.22.2 或更新版本。

```bash
npm ci
npm run dev
```

| 命令         | 范围                       |
| ------------ | -------------------------- |
| 搜索浏览器   | 标签页、书签、历史统一搜索 |
| 搜索标签页   | Chrome 所有可读窗口的标签  |
| 搜索书签     | 所选 Chrome 配置的书签     |
| 搜索历史记录 | 所选 Chrome 配置的最近历史 |

统一入口支持来源下拉框和 `/t`、`/b`、`/h` 前缀，其他入口固定来源。

搜索优先采用标题中的完整命中（包括中文拼音和首字母），再匹配网址或标题与网址的组合，避免网址中的同名片段降低标题相关度。多个词用空格分开；针对短词占用长词位置造成的漏结果增加重试，例如 `git github` 可以找到 `GitHub / git guide`。

统一入口按 `⌘⇧0/1/2/3` 可分别切换全部、标签页、书签、历史记录，也可在 `⌘K` 动作菜单选择来源。切换保留关键词并移除旧来源前缀，例如 `/h zhoubao` 切换到标签页后变为 `zhoubao`。下拉框始终显示当前有效来源，空结果时也能切换。在扩展设置的“来源切换快捷键”中可改用 `⌃⇧0/1/2/3` 或关闭快捷键，更改后重新打开命令。

- 上下键选择，Enter 切换标签或打开地址；失败时保留结果。
- `⌘C` 复制原始完整 URL，`⌘R` 刷新，`⌘K` 打开原生操作菜单。
- 操作菜单可切换 Chrome 配置及打开扩展设置。
- 历史默认读取 20,000 条，上限 100,000 条；全部配置合并后仍受总上限约束。
- 无痕标签默认排除，设置位于 Raycast 扩展偏好。

当前原生列表的标题、网址在同一行展示，行高、灰色选中背景、截断和明暗主题由 Raycast 管理；SDK 没有自定义双行 DOM 布局接口。

## 数据与隐私

浏览数据仅在 Raycast 扩展进程中处理，不上传、不请求远程 favicon、不持久化浏览索引。权限提示归属 **Raycast**。

SQLite 使用只读查询，锁冲突时读取稳定临时快照，不改写 Chrome 源数据库。标签按真实 ID 重新定位，避免关闭或跨窗口移动后误切标签。单来源读取失败保留其他来源。查询序号和数据版本阻止过期结果被复制或打开。
