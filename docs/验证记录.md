# 原生单栏版本验证记录

日期：2026-09-16。本机 Raycast 2.4.1.0、SDK 2.4.1。以下只记录当前原生单栏版本；旧双栏和独立浮窗的验收不算当前版本完成。

## 自动化和构建

- `npm run check`：类型、28 项测试、ESLint、Prettier、Raycast 构建通过。
- `openspec validate restore-raycast-single-list --strict --no-interactive`：通过。
- 回归覆盖 SQLite 锁冲突稳定快照和 WAL、配置发现、书签错误隔离、真实标签 ID、URL 参数化和错误提示。
- 匹配覆盖中文、全拼、首字母、混合、跨字段、Unicode 原始范围、空查询、排序和取消。
- 数据服务覆盖单来源失败、配置加载竞态、关闭无痕、50 条分页、过期查询和过期记录拒绝。
- 20,000 条长 URL 样本在 64 MB old-space 上限内完成连续拼音搜索。

## 2026-09-17 来源切换快捷键

- `PATH=/opt/homebrew/bin:$PATH npm run check`：Node.js 26.8.2，类型检查、33 项测试、ESLint、Prettier 和构建通过。新增 5 项测试先因行为缺失失败，再在实现后通过。
- 真实 Raycast：输入 `/h github`，下拉框同步显示历史；按 `⌘⇧1` 后输入保留 `github`、来源变为标签页。继续按 `⌘⇧2/3/0`，来源分别变为书签、历史、全部。
- 真实 Raycast：输入 `/h github` 后从下拉框选书签，前缀移除，显示 13 个书签匹配；再次按 `⌘⇧2` 仍保留这些结果。
- 真实 Raycast：输入无匹配测试词后按 `⌘⇧1`，仍可切换来源，关键词保持不变。
- `⌃⇧` 与关闭选项已覆盖快捷键映射单元测试，本轮未修改宿主偏好实测；独立入口保持固定来源有逻辑测试，未重复实测全部入口。没有把这些测试计为真实 Chrome 跳转验证。
