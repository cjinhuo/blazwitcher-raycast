## 优先录这四项

1. **`⌘D` 网页预览**：搭配官方 Raycast Browser Extension，在搜索结果旁直接阅读正文，再收起回到单栏。
2. **来源筛选**：说明标签页、书签和历史如何在一个命令中搜索。
3. **打开动作**：说明切换已有标签、新标签打开、当前标签替换和复制的差别。
4. **搜索配置**：展示搜索方式、历史时间范围和读取／显示数量，保存后重新打开命令查看效果。

预览使用可正常读取正文的公开测试页面，并说明需要在 Chrome 中安装并启用官方 Raycast Browser Extension。建议先完成这四类演示和三张商店截图；Chrome 多配置与快捷键演示随后补充。

## 演示数据准备

- 打开你常用且可以公开展示的中文文档、技术网站或文章，用于网页预览、来源筛选及商店截图。
- 默认模式只匹配标题和域名。演示网址路径、参数或片段时，先在“扩展设置 → 搜索方式”选择“完整网址搜索”，重新打开命令后录制。
- 默认历史范围为最近 14 天、最多 1,000 条；历史与书签默认各显示 10 条。准备来源演示时确认页面位于读取范围内，配置演示结束后恢复录制前的设置。
- 为来源筛选准备已打开标签、书签和访问历史中都存在的测试关键词。书签重命名只改变书签标题，不会改变网页标签的标题。
- 打开动作使用独立测试窗口。当前标签替换会改变页面，请先准备一个可以被替换的测试标签。
- 收起无关窗口和通知；检查列表、网址、配置名、剪贴板提示与背景中没有工作数据、账号或私人内容。
- 全套素材使用一致的窗口大小、主题和背景。录制前确认是计划发布的版本。

## Raycast Store 截图

商店截图与 README GIF 分开准备，格式以 [Raycast 官方指南](https://developers.raycast.com/basics/prepare-an-extension-for-store#screenshots) 为准：

- **2000 × 1250，PNG，16:10 横图**。
- 官方建议至少 3 张，最多 6 张。
- 在 Raycast 开发模式中使用 **Window Capture**，选择 **Save to Metadata**。捕获热键由你在 Advanced Preferences 中设置，不是插件的默认热键。
- 放入根目录的 `metadata/`。以下是建议名称，Window Capture 生成的文件可按实际名称保留。
- 统一背景和主题，画面只包含 Raycast 扩展，不展示其他应用或敏感数据。

| 文件                                         | 展示内容                                                                     |
| -------------------------------------------- | ---------------------------------------------------------------------------- |
| `metadata/blazwitcher-raycast-1.png`         | 拼音／首字母输入与中文搜索结果，突出核心能力                                 |
| `metadata/blazwitcher-raycast-2.png`         | `/h` 或 `/b` 筛选、来源信息和结果列表                                        |
| `metadata/blazwitcher-raycast-3.png`         | Actions 菜单，展示打开、复制、来源切换等动作                                 |
| `metadata/blazwitcher-raycast-4.png`（可选） | 公开页面的正文预览，说明依赖官方 Raycast Browser Extension，且正文实际可读取 |

商店截图不作为 README 图片路径的替代：README 使用 `media/`，商店展示使用 `metadata/`。浏览器版的 AI 分组、侧边栏、彩色命中高亮和 `Command+Shift+K` 唤醒演示不适用于此 Raycast 版本。
